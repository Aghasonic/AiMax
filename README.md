## About

**AiMax** is a lightweight, modern crosshair overlay for Windows built with **Python** and **PyQt5**. The goal is simple: give players a beautiful, fully customizable crosshair without heavy resources, ads, or clutter — completely open source.

The UI is flat and minimal, with both light and dark themes.

## Features

**Appearance**
- 9 crosshair shapes: Cross, Dot, Circle, Square, T-Shape, X-Shape, Combo and Triple
- Full control over size, thickness, gap, rotation and opacity
- Custom color with a color picker plus 10 quick swatches
- Outline, Glow and Anti-aliasing effects

**Game Presets**
- CS2, Valorant, Apex, Minecraft, Sniper, Neon, Minimal and Circle
- One click applies all preset values for that game

**Multi-Monitor**
- Choose which display shows the crosshair
- Adjust horizontal and vertical offsets, plus a snap-to-center button

**Profiles**
- Save current settings as a named profile
- Load, rename or delete profiles anytime

**Language & Theme**
- 7 languages: Persian, English, Arabic, Turkish, Russian, Chinese and German
- Light and dark themes, switchable in-app

**System Integration**
- System tray icon with right-click menu
- Global hotkeys: `F8` to toggle, `F9` to quit
- Configurable close behavior (quit, minimize, hide to tray)
- Auto-save settings to `~/.aimax.json`

## Download

Grab the latest **`AiMax.exe`** from the **Releases** page and run it. No Python installation required.

## Hotkeys

| Key | Action |
|-----|--------|
| `F8` | Toggle crosshair visibility |
| `F9` | Quit |

## Important Note

For the crosshair to appear over your game, run the game in **Borderless Windowed** mode. **Fullscreen Exclusive** mode hides transparent overlays, so the crosshair won't be visible.
